# Breezent AI & ICT Training

A premium, animated one-page marketing site for Breezent AI & ICT Training — an EdTech brand offering practical AI, ICT, website design, graphic design, WhatsApp Business setup, and social media management training in Abuja, Nigeria.

## Tech Stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing)
- Tailwind CSS 4
- Framer Motion for scroll-reveal and floating animations
- lucide-react icons
- Netlify Forms for the contact form
- Deployed on Netlify

## Sections

Sticky navbar, hero, animated stats counters, about, "who we teach" cards, services, why-choose-us features, a six-step learning process timeline, testimonials, a gold gradient call-to-action, a contact section with a Netlify Forms-powered enquiry form and embedded map, and a footer — plus a floating WhatsApp chat button.

## Running Locally

```bash
pnpm install
pnpm dev
```

The dev server runs on `http://localhost:3000`.

Netlify Forms submissions only work on a deployed site (Netlify's form-detection and processing happen at build/deploy time, not in local dev).

## Building

```bash
pnpm build
```
